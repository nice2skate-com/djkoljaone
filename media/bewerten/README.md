# Google-Bewertung: Kurzlink und QR-Code

- Kurzlink: **https://dj-kolja-one.de/bewerten** → leitet auf die Google-Bewertung weiter (Plugin-Datei `kjo-bewerten.php`, Ziel in `KJO_BEWERTEN_URL`). Aufrufe werden gezählt (Angebote → Einstellungen → Rechnungen, beim Schlusstext).
- `qr-bewerten.svg` – nur der QR-Code (schwarz auf weiß, beliebig skalierbar, z. B. für Visitenkarte, Aufsteller, Flyer).
- `karte-bewerten.png` / `.pdf` – Karte im DJ-KOLJA-ONE-Look (1200 × 1600 px, 3:4), z. B. ausgedruckt am DJ-Pult oder als Bild in WhatsApp.

Der QR-Code zeigt auf den Kurzlink, nicht direkt auf Google: Ändert sich der Google-Link, nur `KJO_BEWERTEN_URL` anpassen – gedruckte Karten bleiben gültig.
